# Security Policy

## Supported versions

Only the latest release is supported.

## Reporting a vulnerability

Please **don't** open a public issue. Report it privately through [GitHub's private vulnerability reporting](https://github.com/195286381/clawd-pet/security/advisories/new). You should get a reply within a week.

Things worth reporting include anything that lets another process or website reach Clawd's local hook endpoint (`127.0.0.1:47615`) in a harmful way, approve Claude Code permissions without the user, or read data Clawd shouldn't.
